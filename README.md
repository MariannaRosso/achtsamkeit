# Benjamin Ineichen – Personal Website

Source code for the personal website of Benjamin Ineichen, covering meditation and mindfulness, music, science, research, and other interests.

The website is built with Quarto and uses custom HTML, CSS, JavaScript, SVG animations, and media assets.

## Contents
Meditation & Mindfulness – meditation practice, mindfulness, MBSR, and related resources
MBSR Course – information about upcoming MBSR courses in Bern
Music – piano, composition, improvisation, concerts, and musical interests
Research – medical data science, brain research, animal research, and research translation
About – background, research interests, and other projects
Nonsense – a collection of things I find funny

## Built with
Quarto
HTML / CSS
JavaScript
SVG
R / RStudio where applicable

## Development

To preview the website locally:

quarto preview

To render the complete website:

quarto render

The rendered website is generated in the _site/ directory.
